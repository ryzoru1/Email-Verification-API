FAQ

Questions developers ask first

Does verification send an email to the address?

No. The SMTP check, when enabled, performs a best-effort mailbox handshake with the recipient domain. It never sends a message and never reads the mailbox. SMTP is disabled by default because many providers rate-limit or block probing.

How accurate is the result?

Syntax, DNS, disposable and role checks are deterministic. SMTP is best-effort and can be inconclusive. Treat score as a signal, not a guarantee, and set an acceptance threshold that fits your signup flow.

Do you store the email addresses I send?

The service processes addresses in memory to run the checks and does not persist them as a contact database. Request metadata may appear in short-lived operational logs for security and debugging. See the privacy policy.

Can I call the API directly, outside RapidAPI?

The backend supports an optional direct X-API-Key, but the public offering is sold through RapidAPI. Use the RapidAPI key and host headers shown in your dashboard.

What happens when I hit my quota?

RapidAPI enforces plan quotas and returns a rate-limit response. The API also returns standard error codes and a Retry-After header where applicable.
